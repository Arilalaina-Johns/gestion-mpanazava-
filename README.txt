GESTION MPANAZAVA — VERSION MOBILE LOCALE

CONTENU
- index.html : structure de l'application
- style.css : design responsive
- app.js : gestion des membres, branches, activités et sauvegardes
- manifest.webmanifest + sw.js : installation PWA et mode hors ligne
- icon.svg : icône

FONCTIONNALITÉS
- Trois branches uniquement : Mavo, Maitso, Mena
- Listes Beazina et Mpiandraikitra
- Ajout, modification et suppression
- Transfert des Beazina entre branches
- Champ Dingana
- Gestion des activités
- Export/import des données JSON

OUVRIR SUR TÉLÉPHONE
Pour un test rapide, extraire le ZIP et ouvrir index.html dans un navigateur.
Pour installer comme application PWA et bénéficier du mode hors ligne, publier le dossier sur un hébergement HTTPS (par exemple GitHub Pages), ouvrir le lien dans Chrome Android, puis choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».

IMPORTANT
Cette version enregistre les données dans le stockage du navigateur sur un seul appareil.
Elle ne synchronise PAS automatiquement plusieurs téléphones.
Ne publiez pas de données personnelles de mineurs. Protégez les fichiers de sauvegarde.
Pour une synchronisation multi-téléphones, il faudra ajouter un backend sécurisé avec comptes utilisateurs et règles d'accès.
